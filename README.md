# Kill Sheet Calculator

A Python kill sheet calculator for a vertical well with a surface BOP stack,
using oilfield units (ppg, psi, ft, bbl, bbl/ft, spm, bbl/stk).

> **Work in progress.** This project is being built in phases. A full README
> (purpose, how to run it, conventions, example output) arrives in the final phase.
